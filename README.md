# SmartBudget App

## Overview
SmartBudget is an Android application developed using Kotlin.  
It allows users to track expenses, set budget goals, and analyse spending patterns.

## Features
- User login and signup
- Add expense entries
- Attach receipt images
- View expenses list
- Filter expenses by date
- View category totals
- Set minimum and maximum budget goals
- Offline storage using Room Database

## Technologies Used
- Kotlin
- Android Studio
- Room Database
- RecyclerView
- SharedPreferences

## How to Run
1. Clone the repository
2. Open in Android Studio
3. Run on emulator or Android device
